# Product and UI brief

- Job: choose one farm and deliberately copy its complete save between Mac and iPad.
- User: an occasional player, including someone returning after weeks away.
- Risk: replacing the wrong farm or losing newer progress.
- Pattern: farm collection plus a focused compare-and-review workflow.
- First value: scan Mac farms without setup; explain how to connect iPad only when needed.
- Main object: a farm, identified by folder ID as well as its displayed farm name.
- Desktop archetype: library/collection with a transfer work surface and history.
- Window: one resizable window; native menu, search, dialogs, and keyboard focus.
- Distinctive anchor: a two-page farm journal comparing Mac and iPad copies.
- Visual world: original pixel details and [Color Hunt's pink, cream, and sage palette](https://colorhunt.co/palette/f6e2e9fefaf3b8cfb384a282), with square borders and offset shadows inspired by [RetroUI](https://retroui.io/). RetroUI's React components are translated into native Qt styles for this macOS app.
- Typography: readable system body; pixel-inspired display treatment only for short headings.
- Primary action: choose the source copy, then prepare and review a specific transfer.
- Safety: no default source, visible destination consequence, verified backups, cancel before write.
- Speed path: recent farm stays selected after refresh; keyboard selection and review action.
- States: no Mac saves, no iPad, missing dependency, locked/untrusted iPad, scanning, changed save, backup failure, writing, verification failure, success, restore.
- Narrow window: at widths below 900 px, show the farm list first, then a focused comparison with an All farms return button. The primary action stays visible below the scrolling comparison. The supported minimum is 620 × 520 px.
- Evidence: select among multiple farms, compare money, keyboard review, failed/disconnected iPad, prepare/cancel, restore from backup.
